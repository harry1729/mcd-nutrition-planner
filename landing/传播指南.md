# 微信传播指南

## 一个前提纠正

**GitHub 在微信内是可访问的**（实测 200），加载慢的情况主要出现在：
- 首次访问未缓存时
- 仓库首页要加载大量资源（我们的仓库有 21 个文件 + 3 次提交）

**真正的转化瓶颈不是网络，而是「没有入口」。** 好友看到一串 Issue 文字，
不知道这东西对自己有什么用，自然不会点。

落地页的作用：**给一个 3 秒能看懂、且带明显 Star 按钮的中间页。**

---

## 两个产出物

| 文件 | 用途 | 场景 |
|------|------|------|
| `index.html` + `style.css` | 完整落地页 | 发链接、有网环境、想说服人深入了解 |
| `share-cards.html` | 4 张连续长图 | 朋友圈、微信群、对方没耐心点链接 |

两者的 Star 按钮都指向：
```
https://github.com/harry1729/mcd-nutrition-planner
```

## 落地页设计说明

按微信内浏览器的阅读习惯设计，六段式结构：

| 段落 | 内容 | 设计意图 |
|------|------|---------|
| 首屏 | 「20人订午餐预算40块/人」+ Star 按钮 | 3 秒建立关联，CTA 放在首屏不用滑动 |
| 对比表 | 常见团餐工具 vs 本项目 | 差异化一目了然 |
| 结果展示 | 真实终端输出（深色卡片） | 真实感 = 可信度 |
| 数据条 | 107 / 158 / 10 / 45 | 用数字建立权威感 |
| 踩坑复盘 | 4 个真实 bug | 技术社区最吃这套，非技术人群也看得懂 |
| 算法对比 | 贪心 100 vs DP 125 | 建立「这个作者靠谱」印象 |
| 尾部 CTA | 二次 Star 引导 | 滚动到底的人转化最高 |

**技术要点**：
- 移动端优先，375px 基准宽
- 支持深色模式（`prefers-color-scheme`）
- **零外部依赖**：不引任何 CDN、不引字体、不引图片。
  这点很关键——国内网络下任何外部资源都可能拖慢或失败
- 单文件 CSS 内联在外部 `style.css`，便于二次修改
- 按钮 `active` 态有按压反馈，点击手感更明确

## 三种发布方式

### 方式一：直接发文件（最快，适合熟人）

1. 双击 `index.html` 在浏览器打开
2. **手机截图**（或将 HTML 文件发到微信文件传输助手，手机打开后截图）
3. 配文见下方话术

### 方式二：托管后发链接（适合大规模）

**GitHub Pages**（推荐，无需额外账号）：
```bash
# 在项目根目录
touch .nojekyll
git add .nojekyll
git commit -m "启用 GitHub Pages"
git push
```
然后 Settings → Pages → Source 选 `main` 分支 `/ (root)`。
访问 `https://harry1729.github.io/mcd-nutrition-planner/landing/`

**注意**：GitHub Pages 在国内偶尔不稳。若访问不畅，改用腾讯云静态托管
（cos-website 或 EdgeOne Pages，均需实名，国内速度快）。

### 方式三：只用长图（转化最高）

`share-cards.html` 里 4 张 `.shot` 容器，每张 375px 宽。
用浏览器的「整页截图」功能导出长图，或在手机上滚动分段截图。

**建议顺序**：图1（吸引+CTA）→ 图2-4（说服）连发，形成连续感。

## 转化优化清单

提高点击率的几处细节，已在代码里落实：

1. **CTA 放首屏** — 不用滑动就能看到
2. **按钮文案写明动机** —「GitHub 榜单按 Star 排名，这是唯一的加分方式」
   比单纯写「点 Star」转化高，因为它解释了为什么值得点
3. **两处 CTA** — 首屏 + 尾部，覆盖滚动到底的人
4. **真实数字** — 107 餐品 / 45 测试，比形容词可信
5. **深色终端卡片** — 视觉上像真跑出来的，截图时辨识度高
6. **「营养合规方向还是空的」** — 稀缺性暗示，激发支持欲
7. **零外部依赖** — 国内网络下不会因 CDN 失败而白屏

## 合规提醒

推广文案中**必须避免**：

- ❌ 提竞品全名或链接（说「同类作品」即可）
- ❌ 贬低麦当劳、对比其他品牌（规则明令禁止，违者取消资格）
- ❌ 用「秒杀」「最低价」「全网最便宜」等词（踩「宣扬不健康饮食」红线）
- ✅ 引用数据必须真实（107 餐品、45 测试、31.5 元人均都是实测值，别人能核验）
- ✅ 注明「本项目为参赛作品，非麦当劳官方产品」
