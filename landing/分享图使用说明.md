# 分享图使用说明

## 重要前提：微信图片无法点击跳转

微信里发的图片**不能带超链接**——这是平台限制，不是技术问题。

所以本方案用**双保险**：

| 载体 | 作用 |
|------|------|
| **图内印完整地址** | 好友长按复制，或手动输入 |
| **文案里贴链接** | 微信会自动识别成可点击卡片 |

两者缺一不可：图负责吸引 + 说明怎么做，文案负责提供可点击入口。

所有图片为 **2 倍高清**（750px 宽），微信里显示清晰不糊。

## 主图设计说明（shot-a）

这是唯一必须发的图，四层结构从上到下：

1. **绿底标题区** — 「20人订午餐 预算40块/人 到底点什么？」直接用提问开场，让人代入
2. **实测结果卡** — 灰底卡片，显示真实方案与官方复核结论，建立可信度
3. **黄框三步指引** — 本图核心。明确告诉对方「怎么帮我」：
   - 1️⃣ 点下面黑框里的地址，在浏览器打开
   - 2️⃣ 进到项目页面后，点右上角的 ☆ Star 按钮
   - 3️⃣ 就完成了，**不需要注册、不需要下载**
4. **黑底地址块** — 荧光绿等宽字体显示 `github.com/harry1729/mcd-nutrition-planner`，方便长按复制

底部还有一行说明**为什么要 Star**（比赛按 Star 排名），
以及稀缺性提示（营养合规方向还没人做）。

**第三步特意强调「不需要注册、不需要下载」** —— 很多人看到「注册」就会犹豫，
这句能显著降低行动门槛。

## 发送方式

### 方式一：单图 + 文案（推荐，转化最高）

发 `shot-a.png`，配文：

```
20人订午餐人均40 到底点什么？
写了个工具直接给能下单的清单，帮忙点个 Star ⭐

（做法：点下面地址 → 进页面右上角点 ☆ Star，3秒搞定）
github.com/harry1729/mcd-nutrition-planner
```

微信会把地址识别成可点击卡片，图片负责吸引和解释。

### 方式二：四张连发

`a → b → c → d` 依次发，形成信息递进：
痛点吸引 → 差异说服 → 技术可信 → 二次引导。

适合发技术群或想详细说明的对象。

### 方式三：朋友圈

只发 `a` + `d` 两张（首尾呼应），中间两张留给愿意深聊的人私聊索取。

## 重新生成图片

改了文案或数据后：

```bash
cd landing
./export-png.sh
```

脚本会自动测量每张卡片高度并按 2x 导出，无需手动调参。
依赖本机 Google Chrome。

## 合规提醒

文案与图片中**必须避免**：

- ❌ 提竞品全名或链接（说「同类工具」即可）
- ❌ 贬低麦当劳、对比其他品牌（规则明令禁止，违者取消资格）
- ❌ 用「秒杀」「最低价」「全网最便宜」（踩「宣扬不健康饮食」红线）
- ✅ 引用数据必须真实（107 餐品、45 测试、¥31.50 人均均为实测值）
- ✅ 底部保留「本项目为参赛作品，非麦当劳官方产品」
