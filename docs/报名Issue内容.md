## 为什么这样写（定位说明）

本届已有 3 个高度相似的团餐/聚会类 Issue，同质化严重：

| Issue | 项目 | 作者 | 定位 | Star |
|-------|------|------|------|------|
| #775 / #774 | mcd-party-planner | zcbacxc | 派对预约 + 团餐三档粗选 | 794 |
| #861 | 团餐预算官 | tsuiyinlock | 凑单 + 预算清单 | 0 |

**观察**：这两个项目的简介里，"营养""过敏原""钠""蛋白"**一个词都没出现**。
它们的共同短板是——只回答「多少钱、点什么」，不回答「能不能吃」。

**所以本项目的定位刻意避开"团餐预算"这个已被占据的语义锚点**，
改用「**营养合规**」作为主标签：

| 维度 | 同类作品 | 本项目 |
|------|---------|--------|
| 营养约束 | 无 | 蛋白下限 + 钠上限双硬约束 |
| 过敏原 | 不涉及 | 硬过滤 + 剔除原因可追溯 |
| 选品算法 | 启发式粗选 | 二维背包 DP（可证最优） |
| 目标函数 | 最小化人均成本 | 预算内最大化营养质量 |
| 非主食误选 | — | 按真实分类语义判定（曾把 ¥3 酱料包选成 20 人主食） |
| 可验证性 | — | 45 个单元测试，无 Token 也能复现 |

**关键词策略**：简介里刻意堆入 `营养合规 / 蛋白质下限 / 钠上限 / 过敏原规避 / 二维0/1背包DP`
这些**竞品简介里没有的词**。既方便评委和机器人区分，也让搜"营养""过敏原"的
用户能搜到你——而搜"团餐"你会被 794 星的对手淹没。
